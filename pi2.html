Standar Alokasi Pinout & Tegangan Logika (Hardware Limit)

Perhatikan spesifikasi operasional pinout GPIO Raspberry Pi berikut sebelum menyambungkan komponen fisik:

  • Logic Level Voltase: 3.3V Logika High (TIDAK toleran terhadap masukan 5V langsung).
  • Pin Output Digital (LED): GPIO 17 (Pin Fisik 11) — Gunakan Resistor Serial (220Ω – 330Ω).
  • Pin Input Digital (Push Button): GPIO 2 (Pin Fisik 3) — Menggunakan Pull-Up Internal bawaan library.
  • Ground (GND): Pin Fisik 6, 9, 14, 20, atau 34.

Persyaratan Perangkat Keras (Hardware)

Tahap 2: Implementasi Digital Output (LED Blink & Control) Digital Output ▼

1. Buat berkas Python baru bernama led_blink.py menggunakan editor nano:

nano led_blink.py

2. Salin dan tempelkan kode program berikut:

from gpiozero import LED
from time import sleep

# Inisialisasi LED pada GPIO 17 (Pin 11)
led = LED(17)

print("Memulai Program LED Blink (Ctrl+C untuk berhenti)...")

try:
    while True:
        led.on()
        print("Status: HIGH (LED Menyala)")
        sleep(1)
        led.off()
        print("Status: LOW (LED Mati)")
        sleep(1)
except KeyboardInterrupt:
    print("\nProgram dihentikan secara aman.")
    led.close()

3. Simpan berkas (Tekan Ctrl+O → Enter → Keluar Ctrl+X), lalu jalankan program:

python3 led_blink.py
Tahap 3: Implementasi Digital Input (Pembacaan Push Button) Digital Input ▼

Pada tahap ini, skrip Python akan membaca kondisi masukan sakelar (digital input) pada GPIO 2 untuk mengendalikan keluaran LED pada GPIO 17 secara interaktif (Event-Driven).

1. Buat berkas baru bernama button_control.py:

nano button_control.py

2. Salin kode program di bawah ini:

from gpiozero import LED, Button
from signal import pause

led = LED(17)
button = Button(2) # GPIO 2 terhubung ke Push Button

# Registrasi Callback Event Interupsi Input
button.when_pressed = led.on
button.when_released = led.off

print("Sistem Siap! Tekan Push Button pada GPIO 2...")
pause() # Menjaga proses Python tetap aktif menantikan interupsi

3. Jalankan skrip Python input tersebut:

python3 button_control.py
