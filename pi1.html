Target Pembelajaran (SubCPMK-002-2-1)

Mahasiswa mampu mengonfigurasi dan mengembangkan sistem embedded berbasis Raspberry Pi, termasuk instalasi OS, struktur Linux, terminal, konfigurasi SSH, dan komunikasi jaringan secara headless (tanpa monitor, keyboard, dan mouse tambahan).

Parameter Akses Sistem (Pra-Konfigurasi)

Gunakan kredensial berikut selama seluruh alur praktikum:

  • Hostname: apeldua (Domain lokal: apeldua.local)
  • Username: apel
  • Password: 123456
  • Perintah SSH Terminal: ssh apel@apeldua.local atau ssh apel@apeldua

Persyaratan Perangkat Keras (Hardware)

  • Raspberry Pi Zero 2 W (Board utama)
  • MicroSD Card (Minimal 16 GB, Class 10) + Card Reader
  • Kabel Micro-USB to USB-A (Untuk daya/koneksi daya)
  • Laptop Mahasiswa (Memiliki koneksi Wi-Fi/Hotspot)
  • Wi-Fi Router / Mobile Hotspot (Nama SSID & Password diketahui)

Persyaratan Perangkat Lunak (Software)

  • Raspberry Pi Imager (Aplikasi flasher resmi)
  • Terminal / PowerShell / Command Prompt (Bawaan OS Laptop)
  • Network Scanner Application (Fing App di smartphone / Advanced IP Scanner di Windows - Opsional)
Tahap 1: Flashing OS & Pre-Configuration (Raspberry Pi Imager) Software ▼
  1. Masukkan Kartu MicroSD ke Card Reader dan hubungkan ke laptop.
  2. Buka aplikasi Raspberry Pi Imager.
  3. Klik CHOOSE OS → Pilih Raspberry Pi OS (32-bit) / Raspberry Pi OS Lite (64-bit) (Disarankan versi *Lite* untuk sistem tanpa GUI).
  4. Klik CHOOSE STORAGE → Pilih kartu MicroSD yang terdeteksi.
  5. Klik tombol NEXT. Ketika muncul dialog untuk menerapkan setelan kustomisasi (*Use OS customization settings*), pilih EDIT SETTINGS.
  6. Atur parameter kustomisasi sebagai berikut:
    • Hostname: apeldua
    • Set username and password: Username = apel | Password = 123456
    • Configure wireless LAN: Masukkan SSID (Nama Wi-Fi/Hotspot) dan Password Wi-Fi yang sedang digunakan oleh laptop Anda.
    • Wireless LAN country: ID (Indonesia)
    • Masuk ke tab SERVICES → Centang Enable SSH → Pilih Use password authentication.
  7. Klik SAVE, lalu pilih YES untuk memulai proses pemformatan dan penulisan citra OS. Tunggu hingga selesai dan lakukan eject kartu MicroSD.
Tahap 2: Pengkabelan & Integrasi Jaringan (Hardware Setup) Hardware & Network ▼

Arsitektur Koneksi Headless:

  • MicroSD: Masukkan kartu MicroSD yang sudah di-flash ke slot MicroSD Raspberry Pi Zero 2 W.
  • Sumber Daya: Tancapkan kabel Micro-USB ke port berlabel PWR IN pada Raspberry Pi Zero 2 W, lalu hubungkan ujung USB-A ke port USB laptop atau adaptor daya 5V.
  • Koneksi Jaringan: Pastikan Raspberry Pi Zero 2 W dan Laptop terhubung pada akses poin/Wi-Fi/Hotspot yang sama. Saat booting, Raspberry Pi akan otomatis menyambung ke jaringan tersebut secara nirkabel.
Tahap 3: Remote Login via SSH (Terminal Laptop) Terminal & SSH ▼

Buka Terminal (macOS/Linux) atau PowerShell / Command Prompt (Windows) di laptop masing-masing.

1. Jalankan perintah SSH menggunakan mDNS hostname:

ssh apel@apeldua.local

2. Jika muncul peringatan keamanan (Fingerprint confirmation), ketik yes lalu tekan Enter.

3. Masukkan password saat diminta:

123456

Note: Karakter password tidak akan tampil di layar saat diketik (sistem keamanan Linux).

4. Jika koneksi mDNS gagal, cari IP Address Raspberry Pi melalui perintah scan lokal atau tabel klien Hotspot smartphone Anda, lalu ketik:

ssh apel@<ALAMAT_IP_RASPBERRY>
Tahap 4: Eksplorasi Struktur Direktori & Perintah Dasar Linux Linux Structure ▼

Setelah berhasil masuk ke sistem, jalankan perintah-perintah dasar Linux berikut untuk memahami struktur hierarki direktori:

1. Memeriksa lokasi direktori aktif dan identitas sistem:

pwd
whoami
hostname -I

2. Eksplorasi Struktur Root Linux (/):

cd /
ls -la

3. Pengelolaan Berkas dan Direktori Latihan:

cd ~
mkdir praktikum1
cd praktikum1
echo "Sistem Tertanam Untirta 2026" > info.txt
cat info.txt
Tahap 5: Visualisasi Interaktif Pohon Direktori Linux (FHS) Modul Interaktif ▼

Klik salah satu direktori pada skema pohon di sebelah kiri untuk mempelajari fungsi dan direktori Linux secara detail:

/ (Root Directory)
├── /bin & /sbin
├── /boot
├── /dev
├── /etc
├── /home
└── /home/apel
├── /proc & /sys
├── /var
└── /var/log
└── /usr

Akar tertinggi dari seluruh hirarki direktori di sistem operasi Linux. Semua file dan perangkat terhubung di bawah direktori ini.
