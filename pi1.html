Panduan Praktikum Interaktif: Headless Setup & VNC Remote Raspberry Pi

Kembali ke Raspberry Pi
Kemajuan Praktikum Anda 0% Selesai (0/7 Checkpoint)

Target Pembelajaran

Mahasiswa mampu mengonfigurasi dan mengembangkan sistem embedded berbasis Raspberry Pi secara headless, meliputi instalasi OS, struktur Linux, SSH remote terminal, pengaktifan layanan VNC Server via raspi-config, remote Desktop via TigerVNC Viewer, serta pemecahan masalah (troubleshooting) koneksi tampilan GUI.

Parameter Akses Sistem (Pra-Konfigurasi)

Gunakan kredensial berikut selama seluruh alur praktikum:

  • Hostname: apeldua (Domain lokal: apeldua.local)
  • Username: apel
  • Password: 123456
  • Perintah SSH Terminal: ssh apel@apeldua.local atau ssh apel@apeldua

Persyaratan Perangkat Keras (Hardware)

  • Raspberry Pi Zero 2 W / Pi 4 / Pi 5 (Board utama)
  • MicroSD Card (Minimal 16 GB, Class 10) + Card Reader
  • Kabel Micro-USB / USB-C (Untuk daya/koneksi daya)
  • Laptop Mahasiswa (Memiliki koneksi Wi-Fi/Hotspot)
  • Wi-Fi Router / Mobile Hotspot (SSID & Password sama)

Persyaratan Perangkat Lunak (Software)

  • Raspberry Pi Imager (Flasher resmi OS)
  • Terminal / PowerShell (Klien CLI Bawaan OS)
  • TigerVNC Viewer (Aplikasi Klien VNC Remote Desktop GUI)
  • Network Scanner (Fing / Advanced IP Scanner - Opsional)
Tahap 1: Flashing OS & Pre-Configuration (Raspberry Pi Imager) Software ▼
  1. Masukkan Kartu MicroSD ke Card Reader dan hubungkan ke laptop.
  2. Buka aplikasi Raspberry Pi Imager.
  3. Klik CHOOSE OS → Pilih Raspberry Pi OS (32-bit / 64-bit).
  4. Klik CHOOSE STORAGE → Pilih kartu MicroSD yang terdeteksi.
  5. Klik tombol NEXT. Ketika muncul dialog kustomisasi OS (*Use OS customization settings*), pilih EDIT SETTINGS.
  6. Atur parameter kustomisasi sebagai berikut:
    • Hostname: apeldua
    • Set username and password: Username = apel | Password = 123456
    • Configure wireless LAN: Masukkan SSID & Password Wi-Fi/Hotspot yang sedang aktif di laptop Anda.
    • Wireless LAN country: ID (Indonesia)
    • Masuk ke tab SERVICES → Centang Enable SSH → Pilih Use password authentication.
  7. Klik SAVE, pilih YES untuk menulis citra OS, lalu tunggu hingga selesai dan eject MicroSD.
Tahap 2: Pengkabelan & Integrasi Jaringan (Hardware Setup) Hardware & Network ▼

Arsitektur Koneksi Headless:

  • MicroSD: Masukkan kartu MicroSD ke slot Raspberry Pi.
  • Sumber Daya: Tancapkan kabel daya ke port berlabel PWR IN (atau USB Power pada Pi 4/5), hubungkan ke laptop/adaptor daya 5V.
  • Koneksi Jaringan: Pastikan Raspberry Pi dan Laptop terhubung pada akses poin/Wi-Fi/Hotspot yang sama. Pi akan otomatis terhubung saat selesai booting.
Tahap 3: Remote Login via SSH (Terminal Laptop) Terminal & SSH ▼

Buka Terminal (macOS/Linux) atau PowerShell / Command Prompt (Windows) di laptop Anda.

1. Jalankan perintah SSH menggunakan mDNS hostname:

ssh apel@apeldua.local

2. Jika muncul peringatan keamanan (Fingerprint confirmation), ketik yes lalu tekan Enter.

3. Masukkan password saat diminta:

123456

Note: Karakter password tidak akan tampil di layar saat diketik (fitur keamanan Linux).

4. Jika mDNS gagal, cari IP Address Raspberry Pi via scanner jaringan/Hotspot smartphone, lalu jalankan:

ssh apel@<ALAMAT_IP_RASPBERRY>
Tahap 4: Aktivasi VNC Server & Auto-Boot Desktop via raspi-config VNC Setup ▼

VNC (Virtual Network Computing) memungkinkan Anda mengakses antarmuka grafis (GUI Desktop) Raspberry Pi secara nirkabel dari laptop tanpa perlu monitor fisik.

1. Buka Menu Konfigurasi Raspberry Pi:

sudo raspi-config

2. Aktifkan VNC Server:

  • Pilih menu 3 Interface Options → Tekan Enter.
  • Pilih opsi I2 VNC (atau opsi VNC).
  • Ketika diminta mengonfirmasi *"Would you like the VNC server to be enabled?"*, pilih <Yes>.
  • Tekan Enter pada konfirmasi *"The VNC server is enabled"*.

3. Konfigurasi Booting ke Desktop Mode:

  • Pilih menu 1 System Options → Tekan Enter.
  • Pilih opsi S5 Boot / Auto Login.
  • Pilih opsi B4 Desktop Auto Login (atau B3 Desktop) agar Desktop GUI dimuat otomatis saat sistem dinyalakan.
  • Gunakan tombol panah kanan untuk memilih <Finish>.
  • Ketika muncul dialog *"Would you like to reboot now?"*, pilih <Yes>. Sesi SSH akan terputus otomatis karena Pi melakukan restart.
Tahap 5: Remote Desktop GUI Menggunakan TigerVNC Viewer TigerVNC Client ▼

Gunakan klien VNC ringan seperti TigerVNC Viewer di laptop Anda untuk terhubung ke Raspberry Pi.

  1. Unduh dan pasang aplikasi TigerVNC Viewer dari situs resmi atau GitHub/SourceForge.
  2. Buka aplikasi TigerVNC Viewer di laptop Anda.
  3. Pada kolom VNC Server, masukkan IP Address atau hostname Raspberry Pi (contoh: 192.168.1.50 atau apeldua.local).
  4. Klik Connect. Jika muncul peringatan sertifikat keamanan (*Security Warning*), pilih Yes / Continue.
  5. Masukkan kredensial login saat diminta:
    • Username: apel
    • Password: 123456
  6. Klik OK. Tampilan layar Desktop Raspberry Pi OS akan muncul di jendela laptop Anda.
Tips Penggunaan TigerVNC: Tekan tombol F8 pada keyboard saat jendela TigerVNC aktif untuk menampilkan menu kontrol (Full Screen, Options, Disconnect). Anda juga dapat mengatur resolusi dan ukuran ikon melalui menu Preferences → Appearance Settings di Raspberry Pi OS.
Tahap 6: Troubleshooting VNC & Prosedur Shutdown yang Benar Maintenance & Fix ▼

1. Pemecahan Masalah: Layar Abu-abu (Gray Screen) / Blank pada VNC

Jika koneksi VNC berhasil tetapi hanya menampilkan layar abu-abu tanpa ikon desktop, lakukan pembaruan paket sistem via SSH terminal:

sudo apt update
sudo apt upgrade -y
sudo reboot

Proses pembaruan ini akan mengunduh repositori GUI terbaru dan memperbaiki paket driver tampilan yang hilang.

2. Prosedur Matikan (Shutdown) Raspberry Pi yang Benar

Jangan mencabut kabel daya secara langsung saat sistem beroperasi karena dapat merusak berkas pada kartu MicroSD. Gunakan salah satu metode berikut:

  • Melalui GUI VNC: Klik menu utama (logo Raspberry) → Pilih Shutdown → Klik Shutdown.
  • Melalui SSH Terminal: Jalankan perintah berikut sebelum mencabut kabel daya:
sudo shutdown -h now

Tahap 8: Tugas Mandiri — Bukti SSH dengan Host Name Nama Sendiri Tugas Mandiri ▼

Setia mahasiswa diwajibkan mengubah Hostname Raspberry Pi menggunakan Nama Mahasiswa / NIM Sendiri, melakukan login via SSH, dan mengunggah/menampilkan bukti screenshot terminal SSH yang menampilkan prompt terminal berisikan nama sendiri.

Langkah-langkah Tugas Mandiri:

  1. Buka SSH Terminal laptop yang terhubung ke Raspberry Pi.
  2. Ubah Hostname Raspberry Pi menjadi nama Anda (contoh: budi-pi atau nim3331001) dengan menjalankan perintah: 
    sudo hostnamectl set-hostname NAMA_ANDA
    Atau ubah melalui menu sudo raspi-config → 1 System Options → S4 Hostname.
  3. Lakukan reboot sistem agar nama host baru diterapkan: 
    sudo reboot
  4. Hubungkan kembali SSH dari laptop menggunakan hostname baru: 
    ssh apel@NAMA_ANDA.local
  5. Ambil tangkapan layar (screenshot) layar Terminal yang menampilkan prompt terminal dengan nama baru Anda (contoh: apel@budi-pi:~ $).
  6. Unggah file gambar bukti screenshot Anda pada area di bawah ini untuk verifikasi:

Format yang didukung: PNG, JPG, JPEG, WEBP
